\chapter{Conclusion}
\label{cha:conclusion}

This thesis aimed to develop and validate a robust pipeline for detecting human movement from fiber optic sensing data. To achieve this goal, this work presented the spectrogram classifier framework, an end-to-end system designed to process raw Distributed Acoustic Sensing (DAS) phase data and classify human footsteps. The framework's methodology transforms the raw, one-dimensional signal into two-dimensional spectrograms, which are then fed into modern Convolutional Neural Networks (ConvNeXt V2 and EfficientNet) for classification.

The success of the framework was rigorously evaluated by training and testing the models on two distinct dataset configurations: a single spatial channel setup (Dataset-1D) and a more complex ten-channel setup (Dataset-2D). The results of this comparison delivered the central finding of this thesis:

\begin{itemize}
\item Models trained on the ten-channel dataset (Dataset-2D) were highly successful, achieving testing accuracies above 99\%. In real-time evaluations, these models produced a clear and accurate footstep trail with very few false positives, demonstrating the framework's effectiveness for reliable detection and localization.

\item In contrast, models trained on the single-channel dataset (Dataset-1D) proved insufficient for a reliable application. While their offline testing accuracies were acceptable (87.55\% and 91.89\% respectively), they generated a high number of false alarms on neighboring spatial channels during real-time evaluation, making it difficult to pinpoint the true location of footsteps.
\end{itemize}

Ultimately, this work successfully demonstrates the viability of the spectrogram classifier framework. The key conclusion is that while the general approach is sound, the inclusion of multi-channel spatial data is critical. The richer spatial context provided by ten channels allows the models to effectively learn the difference between a true event and spatial noise, moving the system from a simple proof of concept to a reliable, field ready foundation.

\section{Future Work and Perspective}
\label{sec:future_work_perspective}

Building on the framework validated in this thesis, several key areas for future work can enhance its capabilities and broaden its application, moving it toward a comprehensive perimeter monitoring platform.

A key opportunity lies in iterative dataset improvement. The current evaluation reveals that false positives still occur, particularly in noisy environmental zones. The evaluation framework's ability to save all detections as \texttt{.npy} files is a powerful feature for addressing this. These false positives can be manually identified and added to the background training set. Retraining the model on this enriched dataset would teach it to ignore these specific noise patterns. While increasing the detection threshold (\texttt{min\_prob}) can reduce alarms, it risks missing fainter but legitimate footsteps; this iterative feedback loop is a more robust method for improving model precision without sacrificing sensitivity.

The second major avenue is the expansion to other critical activities. The current framework provides a strong foundation for footstep detection, but a true perimeter security system must identify other threats. The model and training pipeline can be extended to classify events like fence cutting, climbing, and digging. This would require collecting and annotating new datasets for these activities and transitioning the model from a binary classifier to a multi-class classifier. By doing so, the system would evolve into a far more capable and versatile surveillance tool, suitable for deployment in high-security locations like airports and national borders.

In perspective, this thesis has successfully moved beyond a simple lab experiment. By proving the effectiveness of the Spectrogram Classifier Framework and establishing the critical need for multi-channel data, it provides a clear and validated path toward a general-purpose, scalable, and highly reliable DAS-based security platform.
